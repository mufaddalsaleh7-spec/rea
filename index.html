Open the web workspace

React 19 front end with a PHP document API: revisioned saves, conflict handling, server-side SVG export and published PNG links. Runs offline in browser-draft mode when the API is absent.

Built alongside REA and VectorCraft. The web workspace's PHP API is not part of this static host — run it locally with npm start in apps/vectorstudio-web for cloud saving.
